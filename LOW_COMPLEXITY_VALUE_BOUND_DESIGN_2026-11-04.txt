WHY THIS TEST
The prior 72,000-slot run improved returns and deadline success during
training, but all three model architectures violated the known nonpositive
finite-horizon Q bound. Positive greedy Q occurred on every common heuristic
probe state and roughly43%-59% of final replay states. The failure therefore
was shared by EMC-Q, additive64 and additive128. The previous completed result
and read-only diagnosis remain unchanged.

TREATMENT
Five arms isolate architecture from a value-sign constraint:

- additive128_unbounded: original wide reference.
- additive64_unbounded: original compact reference.
- emc_q_unbounded: original exact-decoder EMC-Q ablation.
- additive64_nonpositive: compact architecture with the sign constraint.
- emc_q_nonpositive: primary treatment, same EMC-Q architecture with the sign
  constraint.

For each constrained arm, define Q_b(s,a) = -softplus(Q_raw(s,a)). This is
finite and nonpositive for every finite raw output and introduces no learned
parameters. It does not guarantee accurate magnitude or a good policy. The
development screen must still test return, deadline success, calibration,
storage and inference latency.

EXACT ACTION SELECTION REQUIREMENT
Negative softplus is monotonically decreasing. Therefore the action maximizing
Q_b is the action minimizing Q_raw. For additive64, independently minimize
each of its32 raw action heads, sum the selected raw scores, then transform
that scalar. For EMC-Q, the exact restricted decoder must minimize the raw
joint score. Equivalently, negate its unary, joint movement and rank-2 factor
tables, leave gates and movement embeddings unchanged, and run the existing
exact maximizer; then evaluate Q_b for that selected action. Transforming the
value after the existing raw maximizer is wrong and will choose the wrong
action. This decoder equivalence is checked by exhaustive enumeration on a
small random action space before implementation.

The same rule applies in Double DQN: online selection minimizes raw Q for
constrained models; target evaluation uses that selected action and applies
the identical negative-softplus output transform under no-grad. Absorbing
successors remain excluded. Unbounded controls retain raw argmax. The runner
must implement these paths independently and test them before any smoke.
