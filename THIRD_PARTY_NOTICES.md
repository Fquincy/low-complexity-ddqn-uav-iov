# Ownership and third-party material

This export preserves existing research source and notices. No new blanket
software license was selected during packaging. Repository visibility alone
does not resolve reuse rights. The owner should select an appropriate code
license after reviewing authorship and third-party dependencies.

Downloaded academic PDFs and full-paper extracts are excluded from this export.
Use the DOI/publisher links in the reference notes. Dependency packages have
their own licenses and are installed separately. Historical results and figures
must retain their measured/illustrative status; do not treat constructed plots
as experimental evidence. GitHub's existing Python ignore template is retained.
