PROSPECTIVE DESIGN: VALUE-GRADIENT ISOLATION IN THE COMPACT DDQN
20 November 2026
DESIGN DECISION ONLY - NO CONTROLLER IMPLEMENTATION OR RESEARCH RELEASE

1. DECISION AND PURPOSE
Test ONE training change to the existing calibrated, policy-retaining DDQN:
block the state-value output's gradient into the shared features, while
keeping its value readout, decision branches and shared features trainable.
The inference function, parameter count, action screen and decoder stay
the same. This is a correction to an existing compact DDQN, not a claim
that we invented a new neural architecture or solved the thesis contribution.

The design has a specific motivation, not a guarantee of better learning.
It removes the locally verified value-to-feature gradient path and retains
branch-dependent TD learning. It may preserve good decisions, fail to learn
beyond imitation, or worsen values. Measure all of those outcomes.
Do not run another research comparison until isolated mechanics, protocol
freeze, runner/auditor fixture and launch-readiness gates are complete.

3. DEPLOYMENT EQUATIONS: SAME FOR PROPOSAL AND PAIRED ABLATION
Let h_phi(s)=ReLU(W_h s+b_h), with d=533 and width h=24.
The affine output has 161 rows: 150 placement, 10 movement, one V readout.
Divide placement outputs by 30 and movement outputs by 2, as before.
For 32 branches and 5 actions each, denote scaled branch costs z_b,d(s):
  C_phi,psi(s,a) = sum_b [z_b,a_b(s)-mean_(d=0..4) z_b,d(s)]
  V_phi,w(s) = w_V^T h_phi(s)+b_V
  Q(s,a) = V_phi,w(s)-C_phi,psi(s,a).

For a nonterminal state:
  a_b* = argmin_(d in inherited_allowed_b(s)) z_b,d(s).
Retain the conservative local feasibility mask and first-index ties.
Terminal next states bypass decoding and bootstrap zero. No teacher,
simulation, projection, queue lookahead, candidate reranker, destination
repair or new deployment input is added. The decoder exactly maximizes
the additive critic; it does not exactly optimize coupled physical queues.

4. THE ONLY PROPOSED CHANGE: TRAINING GRADIENT ROUTING
During the online TD loss, use the following surrogate differentiation:
  Q_tilde(s,a) = w_V^T stopgrad(h_phi(s))+b_V-C_phi,psi(s,a).
Numerically Q_tilde equals Q at identical weights and inputs. Inference
uses the original Q. The change is the backward path, not a new Q offset.

For replay batch size N, retain detached Double-DQN target selection:
  a_next = decode_online(s_next)
  y = r+(1-done)*Q_target(s_next,a_next), gamma=1
  L_TD = mean Huber_beta1(Q_tilde(s,a)-stopgrad(y))
  L = L_TD + L_keep.
L_keep is the existing masked branch imitation loss, at the fixed handoff
temperature alpha, on separately sampled saved demonstration actions.

Writing delta_n=Huber'(Q_tilde_n-y_n)/N:
  grad_phi L_TD = -sum_n delta_n grad_phi C(s_n,a_n)
  grad_wV L_TD = sum_n delta_n h_phi(s_n)
  grad_bV L_TD = sum_n delta_n
  grad_psi L_TD = -sum_n delta_n grad_psi C(s_n,a_n).
The imitation loss still trains phi/psi, with zero direct V-readout gradient.
The ordinary baseline also includes sum_n delta_n grad_phi V(s_n); the
proposal removes exactly that term. It does NOT freeze the encoder, replace
DDQN with BC, detach all TD gradients, or change which next action is chosen.

This is an explicitly modified semi-gradient rule. It is not the ordinary
gradient of the original coupled scalar objective with respect to all
parameters. No descent, convergence, optimal-policy or calibration theorem
is claimed. Readout values still depend on evolving features in the forward
pass, and bootstrap/branch gradients can remain problematic.

5. IMPLEMENTATION CONTRACT FOR THE LATER ISOLATED MECHANICS GATE
Implement only in new files; never patch the frozen completed models/runner.
The desired contract is the existing full affine FORWARD operation, with
its output tensor and floating-point behavior preserved. In its BACKWARD:
  dW_out = upstream^T h; db_out = sum(upstream)
  dh = upstream_(first160) W_out_(first160).
This omits only the V row when passing gradient to h. All output-row weight
and bias gradients remain trainable. A custom training-only affine backward
is one possible implementation; independent detached-feature reference
calculations must verify it. Do not silently split/reorder inference GEMMs
or change action ties to obtain numerical parity.

Keep the original inference module/state_dict layout for export. BC must
use its original full gradient rule. Value-row calibration must freeze the
same features/branches as before. Target evaluation is always no-grad.
Routing becomes active only for the declared online TD continuation.
Retention's V-upstream is zero already; its feature/branch derivatives
must remain unchanged. One joint backward and one Adam step per TD update.

7. ACCOUNTING FOR JOINT ALLOCATION: AN EXPLICIT LIMIT, NOT A SECOND CHANGE
All current tasks are present in the observation, so the shared encoder can
in principle learn state-dependent coordination. No impossibility claim is
made. However, an accurate separable decoder alone cannot guarantee balanced
same-slot assignments or deadlines. Blocking V gradients does not add an
explicit physical interaction term or capacity constraint.

A two-task algebraic counterexample illustrates the limit: each independent
branch prefers the same server with service time0.2s/task. With deadline0.3s,
the second queued task misses; independent local CPUs at0.25s/task meet both
deadlines. Exact maximization of the preferred additive scores still chooses
the congested server. This is a toy accounting check, not simulator evidence.

The proposed test asks whether preserving/improving existing branch learning
reduces observed allocation failures. Report destination matrices, assigned
cycles per server/slot, task-matched misses and within-slot wait decomposition.
If allocation quality remains deficient, record failure. Do not add a new
repair/price term mid-run or claim that the queue problem has been solved.

10. REQUIRED BROADER COMPARISON BEFORE A THESIS EFFICIENCY CLAIM
The nine-arm test is a narrow mechanism study. It cannot prove compression
against equal-size models, establish general superiority or settle novelty.
A later source-bound comparison must include larger-capacity 64/128-hidden
DDQN references, an explicitly adapted BDQ reference, a properly specified
DQfD-style reference, the same ordinary small DDQN, E/F and relevant heuristics
(observed-load/radio, all-local, nearest-RSU and UAV-selective).

reward/deadline accounting and clearly disclosed masks/data exposure. A
physically legal all-local heuristic may choose actions excluded by the
learned deadline screen; such a baseline exemption must be explicitly
declared before execution, not silently handled by the learned-policy runner.
Full DQfD requires declared demonstration, TD/n-step/margin, prioritization
and optimization details; the present BC+retention arm is NOT full DQfD.
BDQ needs a declared joint-action adaptation. Existing versions cannot be
silently mixed with these new model definitions or different runtimes.

That broader protocol must freeze definitions, budgets, fairness, quality/
value/cost rules and fresh seeds in its own gate, before training or model
selection. No unsupported numeric equivalence margin is invented here.
An untouched final evaluation with predeclared uncertainty remains required
after model/design lock. Neither broader nor final execution is authorized.

12. TARGETED LITERATURE CHECK: OVERLAP IS REAL
Primary-paper pages, two full HTML papers, query responses and hashes are
saved under validation/value_gradient_isolation_brief_2026-11-20_01/.

Double DQN, https://arxiv.org/abs/1509.06461:
Online action selection and target-network evaluation are established.
Our retained update is DDQN with a declared additional semi-gradient rule.

Dueling, https://arxiv.org/abs/1511.06581:
The full paper explicitly states that BOTH streams propagate gradients into
the shared convolutional layer and rescales their combined gradient by
1/sqrt(2), with gradient clipping. Our selective removal of V's feature
gradient differs from that general rescaling; R tests the adapted alternative.
State-value/advantage factoring and gradient stabilization are not new here.

Action Branching, https://arxiv.org/abs/1711.08946:
Shared representations with per-action-dimension branches and linear output
growth are established. Our additive decoder/compact branch architecture
must not be claimed as the invention of action branching.

DQfD, https://arxiv.org/abs/1704.03732:
Demonstrations plus TD and supervised action learning are established.
Teacher warm-start/retention alone is not our novelty, and full DQfD is a
distinct reference with additional published mechanisms.

Gradient Surgery, https://arxiv.org/abs/2001.06782:
PCGrad projects conflicting task gradients. Our fixed V-path block performs
no conflict test or projection and is not PCGrad. The general concern about
interference and the use of gradient modification are established.

Decoupling Representation Learning from Reinforcement Learning,
https://arxiv.org/abs/2009.08319:
The full paper trains representation with ATC/unsupervised learning while
detaching the encoder from RL gradients. Our encoder still receives branch
TD and imitation gradients, with only V-to-feature TD removed. This is a
different restriction, but gradient blocking/decoupling itself is established.

Application overlap: DQfD-DECO, Enhanced Task Offloading in Mobile Edge
Computing: A Hybrid Approach Using Deep Q-Learning from Demonstrations and
Heuristic Optimization, https://doi.org/10.1109/ICEAAI64185.2025.10956500.
Refreshed Crossref metadata and OpenAlex's indexed abstract describe
heuristic demonstrations followed by adaptive RL for energy/deadlines.
This is indexed abstract evidence, NOT inspection of that method's full text.
The generic workflow already overlaps the proposed application story.

Three broad Crossref queries returned largely irrelevant titles. They do
not establish absence of the exact gradient rule in prior UAV-IoV work.
This bounded check supports a concrete experiment, NOT a first-ever claim.
The prospective contribution is a measured, reproducible compact-DDQN
training improvement in this offloading setting IF it beats its controls
and meets broader efficiency/quality tests. Exact novelty remains unresolved;
a fuller application-specific method comparison is needed before thesis prose.
