# What is published

This is a curated source and research-evidence export made on 21 November 2026.
The private original folders were copied, not moved or overwritten. Frozen
research sources retain their original bytes; `provenance/SOURCE_MAP.json`
identifies each included copy and any navigation-only adaptation.

Personal extension/identity forms, private correspondence, thesis drafts,
credentials, local virtual environments, nested Git histories, caches,
downloaded full papers and unreviewed binary artifacts are excluded. Existing
machine paths in immutable historical protocols describe original provenance;
they are not instructions to recreate those drives or overwrite local files.

Raw training/evaluation trace arrays, optimizer logs, model/checkpoint binaries
and the full private archive are not uploaded. The low-complexity repository
includes an aggregate artifact inventory and selected original audit/manifests.
Full historical reproduction requires obtaining the matching raw artifacts.
An included manifest entry is a recorded hash, not proof that the corresponding
excluded data can be downloaded here. Do not claim this export is the complete
dataset or that all historical tests can run without their original inputs.

No new controller was trained, research protocol changed, seed block allocated
or thesis edited during packaging. The only executed simulator work is a tiny
engineering-only environment check, recorded as such. Public release is not
evidence of scientific acceptance or novelty. See `AGENTS.md` for the allowed
model restriction and research gate boundaries.
